**Vision:** provide a precision tool for knowledge workers that transforms cluttered web pages into clean, structured Markdown, specifically optimized for Obsidian.
- Native extraction of math formulas into `${...}$` and `$${...}$$` syntax.
- Use an AdBlock-style picker to define exactly what to include or ignore, stored in a site-specific tree structure.
- Allow users to define how non-standard elements (like complex dropdowns or custom UI widgets) are represented in Markdown using simple templates.
- One-click "Copy to Clipboard" functionality for configured sites.
